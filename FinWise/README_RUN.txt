HOW TO RUN FINWISE
1. Install Python 3.9+ from python.org (tick "Add Python to PATH") if you don't have it.
2. Windows: double-click run.bat      Any system: open a terminal here and run: python run.py
3. Wait for the browser to open http://127.0.0.1:5000  (first run takes a few minutes).
4. Click the menu button, then "Expense prediction".
In VS Code: File > Open Folder > this folder, open run.py and press the Run (play) button.
Stop the app with Ctrl+C in the terminal.
